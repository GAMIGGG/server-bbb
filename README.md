# King Manager - Servidor de Validación (Vercel)

Este es un backend serverless ultra-ligero diseñado para la fase beta de tu juego en Godot.
Controla que ningún cliente modifique localmente su versión o intente jugar con ejecutables viejos.

### Despliegue rápido:

1. Instala Vercel CLI: `npm install -g vercel`
2. Ejecuta `vercel` en la raíz de esta carpeta.
